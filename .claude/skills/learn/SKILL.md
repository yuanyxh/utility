# 自学习

## 目标

让同类问题不重复发生，同时避免把偶发经验上升为通用规则。

## 步骤

1. **收集事实**：本次会话的缺陷、返工、发布问题或用户纠正，附证据。
2. **判定适用范围**：项目特有、技术栈相关或跨项目通用。
3. **写入项目**：项目特有的教训写入 `.agent/lessons.md`，格式为场景、事实、决策、适用范围。
4. **提议晋升**：跨项目模式按 `protocols/distill.md` 判断，形成种子候选并交用户确认。
5. **去重**：与已有教训或规则同义时合并，不重复记录。

## 完成条件

- 每条教训可追溯到一次具体事件。
- 通用候选未经用户确认不写入种子库。

## 禁止

- 记录没有证据的猜测。
- 把项目名、路径、凭据或业务数据写入通用种子。
- 自动修改 `seeds/`。
