## 绝对守则
- **每阶段自检一**
  - 当前阶段完成 - 跳过，**禁止重复执行、输出阶段内容**
  - 当前阶段失败 - 排查失败原因，**禁止无任何排查过程直接重试**
- **每阶段自检二 - 工具调用**
  - 需要了解**上下文/过往历史/项目/未知内容**吗？ - **执行「记忆搜索」**
  - 需要查找**项目信息/依赖图/代码位置/文件位置**吗？ - **project_search**
    忽视此规则，而先使用 `pattern` 时，**退回重走**
  - 需要**了解项目**吗？ - **proj_init**
  - 需要查找**网络资料/补充内容**吗？ - **websearch-fallback**
  - 需要检查**项目/架构/代码 - 整体健康**吗？ - **health**
  - 需要多维度审查**项目/代码**吗？ - **check**
  - 需要**排查 bug** 吗？ - **hunt**
  - 需要**规划/架构/方案**吗？ - **think**
  - 需要**调整 UI** 吗？ - **ui**
  
  **MCP 工具高于内置工具，无视 MCP 工具直接调用内置工具是绝对禁止行为**
- **每次回复后立即执行，未执行 = 跳步，重走流程，禁止询问，不管任务状态必须执行**
  1. **判断记忆价值**：是否包含：架构/方案设计、用户习惯、关键信息、任务进度，**一切应该被持久化的内容**
  2. **提炼写入**：调用 **remember/remember_batch**
- **一律使用中文，以用户上海时区为主**
- **所有删除操作改为移动到废纸篓**
- **事实为主导**，内容必须有可信来源，方案必须经过验证
- 问题**先排查，确认事实、查找资料**
- Bash **必须避免进程被超时停掉，只设置超时是禁止行为**
- 使用**记忆内容覆盖用户后续修正**是**绝对禁止**行为，必须**立即停止确认**
- **禁止未经明确允许**的提交操作
- 回复干净简洁，技术严谨风，**禁止过度输出**
- **禁止无用、一次性、大段注释，自检：紧连超过两行即禁止写入**
- **文件操作一律绝对路径**；不确定位置先 project_search/Glob 定位
- 读取文件优先一次读足(offset/limit 覆盖所需范围)
  同文件二次读取前先 project_search/project_exports 定位，**禁止整文件重读**
  改前先 git diff 看现状
