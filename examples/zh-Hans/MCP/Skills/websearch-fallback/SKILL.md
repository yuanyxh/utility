> **强制资源获取协议**：当本文要求加载 `scripts/` 目录下的资源时（如 `scripts/search.sh`、`scripts/bing_search.sh` 等指令），必须执行以下步骤：
>
> 1. 调用 `tool_resource` 工具，传参 `parentName: websearch-fallback`、`path: <子目录>/<文件名>`；
> 2. 以 `tool_resource` 返回的内容为准继续执行，禁止凭记忆或猜测代替；
> 3. 脚本获取后，在本地 shell 中执行（Bash），不要用本地文件读取/curl 等其他通道获取脚本内容，`tool_resource` 是唯一允许的获取方式。

# 联网搜索

## 执行流程（按序，禁止跳步）
1. **优先内置 WebSearch 工具**定位关键词，获结构化结果列表。
   
   - 返回空模板（`Web search results for query: X` + 无 Links）或结果数为 0 → 立即切换第 2 步。
   
2. **核心路径：多搜索引擎级联**：
   
   - 使用统一入口脚本 `scripts/search.sh` 抓取多个搜索引擎
   - 支持的引擎：Bing、Google、DuckDuckGo、Brave
   - 默认级联模式：Bing → Google → DuckDuckGo → Brave，直到获得足够结果（≥5条）
   
   ```bash
   # 经 tool_resource 获取脚本内容（parentName: websearch-fallback）
   bash <本skill目录>/scripts/search.sh "关键词1 关键词2"
   ```
   
   - 也可指定单一引擎：
     ```bash
     bash <本skill目录>/scripts/search.sh --engine=google "关键词"
     ```
   
   - 或使用所有引擎合并结果：
     ```bash
     bash <本skill目录>/scripts/search.sh --all "关键词"
     ```
   
3. **深挖正文**：对命中 URL 使用 `read` tool 获取详细内容
   
4. **搜索结果不乐观**：关键词过多 → 减少；过少 → 增加；中文无结果 → 立即换英文，反之亦然。

## 搜索质量（硬性）
- **结果数量**：最少获取 10 份完整、不重复的结果，不足则换关键词补足。
- **关键词精确**：`核心词 + 限定词`（年份 / 类型 / 平台 / 语言），禁止宽泛单短词直接搜。
- **善用语法**：`"精确短语"`（引号匹配）、`site:域名`（限定站点）、`-排除词`（过滤噪音）。
- **强相关过滤**：与关键词无关的内容一律丢弃，只凭「标题 + URL」判断相关性。
- **来源可查**：每条结论必须附真实 URL；无结果如实说明，禁止编造内容或虚构来源。

## 搜索速度（硬性）
- **一次覆盖**：优先一轮搜索同时覆盖多组关键词，减少往返。
- **限次收敛**：单个问题搜索 ≤3 次；多次尝试仍无法达标 → 立即停止，如实告知，禁止反复空转。
- **即时止损**：某关键词 / 引擎明显无结果时立即切换，禁止在同一处重试超过 1 次。

## 搜索引擎选择

| 引擎 | 特点 | 适用场景 |
|------|------|----------|
| Bing | 中文支持好，结果丰富 | 中文内容、国内网站 |
| Google | 全球覆盖，结果质量高 | 英文内容、国际网站 |
| DuckDuckGo | 注重隐私，无追踪 | 隐私敏感场景 |
| Brave | 新兴引擎，结果新颖 | 技术内容、新闻 |

## 隐私说明

- 默认使用本地搜索引擎抓取脚本，URL 不离开本机
- 获取网页详情时，默认使用 `read` tool
- 如需使用代理模式获取 JS 渲染页面，需用户明确同意（`--use-proxy`）
- 禁止对认证、内部或敏感 URL 使用代理模式

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 单个引擎失败 | 继续尝试下一个引擎 |
| 所有引擎失败 | 停止并告知用户，禁止编造结果 |
| `read` 失败 | 告知用户具体失败原因，建议替代方案 |
| 结果不足 | 换关键词重试，最多 3 次 |
| CAPTCHA/403 | 切换到其他引擎，禁止重试同一引擎 |
