# 设计参考：数据可视化

仅当界面是看板、分析视图、图表密集的界面，或任何数字密集的数据展示时加载本文。营销页、落地页与通用组件工作不需要它。

## 看板默认值

看板是工具型界面：定位用户、展示状态、促成操作。不要 hero 区块，不要营销文案。每个元素都必须通过回答用户的某个问题来挣得自己的位置。

- 主布局：状态摘要置顶，细节在下；或侧边栏筛选 + 主图表区。
- 留白：比营销页更紧；用户是扫读，不是细读。用充裕的列间距，而不是充裕的行高。
- 数字密度：同屏出现很多数字不是问题。无对齐的拥挤才是。所有数值列使用 `font-variant-numeric: tabular-nums`。数字右对齐。标签左对齐。

## 图表选型

| 用例 | 图表类型 |
|---|---|
| 比较各类别的取值 | 柱状图（标签较长时用水平柱） |
| 随时间的趋势 | 折线图；点数多的时序避免用柱 |
| 部分与整体关系 | 树图（6+ 段）或堆叠柱；饼图只用于 2-4 段 |
| 分布 | 直方图或箱线图；绝不要饼图 |
| 相关性 | 散点图；不要用折线图 |

超过 4 段的饼图什么也传达不了。改用树图或排序列表。

## 数字密集界面

- 每个数值列都加 `font-variant-numeric: tabular-nums`，让数字纵向对齐。
- 所有数字右对齐；所有文本标签左对齐。同一列里混用对齐方式永远都是错的。
- 微妙的行分隔线：`1px` 线，`rgba(0,0,0,0.06)`（浅色）或 `rgba(255,255,255,0.05)`（深色）。仅当表格非常宽（12+ 列）时才用隔行背景。
- 列间距：相邻列之间至少 `16px`；逻辑上不同的组之间再多一些。

## 用产品作标杆

当用户引用某个产品作为视觉标杆（「做成像 Grafana 那样」/「类似 Linear 的分析」）时：从这个产品抽出 3-5 个具体的数据可视化属性，而不是泛泛的审美属性。有用的属性：图表配色（精确取值）、网格线粗细与不透明度、坐标轴标签字号与颜色、tooltip 圆角与阴影、空状态处理。不要把「极简」或「干净」当作属性抽出；那些不可执行。
