# 界面规则

## UIX-01 状态完整

**规则**：每个数据区域都有加载、空、错误与成功四种状态，并说明可执行动作。

**禁止**：只实现成功状态。

**验证**：断开网络与返回空数据时界面仍可理解。

## UIX-02 反馈及时

**规则**：超过 100 毫秒的操作给出进行中反馈；失败时说明原因与恢复方式。

**禁止**：操作后无任何反馈或只改变鼠标样式。

**验证**：慢网络下用户能判断系统正在做什么。

## UIX-03 一致优先

**规则**：同类元素的文案、间距、交互与错误提示保持一致，优先复用现有模式。

**禁止**：为单个页面发明新的交互范式。

**验证**：同类场景的界面元素可对照一致。

## UIX-04 可访问性

**规则**：满足画像声明的可访问性级别；键盘可完成核心流程。

**禁止**：关键操作只能通过拖拽、悬停或颜色区分完成。

**验证**：键盘与读屏走查通过。
