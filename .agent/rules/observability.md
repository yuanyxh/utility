# 可观测性规则

## OBS-01 关键路径可观测

**规则**：核心用户路径有成功、失败与耗时指标，并带可关联的追踪标识。

**禁止**：线上故障只能靠用户反馈发现。

**验证**：人为制造失败后能在指标或日志中定位。

## OBS-02 告警可行动

**规则**：每条告警说明影响、判断依据与建议动作；无行动项的告警删除或降级。

**禁止**：把日志异常直接配置成告警。

**验证**：告警清单逐条可对应处理步骤。

## OBS-03 成本可见

**规则**：资源、存储与调用成本有周期记录，异常增长时能归因到功能或流量。

**禁止**：不记录成本变化。

**验证**：成本报告可按环境与主要功能拆分。

## OBS-04 日志不含敏感信息

**规则**：日志与追踪中不写入凭据、令牌、个人敏感数据。

**禁止**：为排查方便打印完整请求体。

**验证**：抽样日志中检索不到敏感字段。
