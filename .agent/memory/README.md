# 长期记忆

跨会话可复用的结论文档。与 `decisions.md`（已定决策）、`lessons.md`（教训）分工：

- 本目录存**事实与做法**（命令、路径、机制说明）
- 决策写 `decisions.md`
- 教训写 `lessons.md`

## 文件约定

- 一主题一文件，文件名用 kebab-case
- 每条结论标注日期与来源（命令输出 / 代码位置 / 官方文档）
- 过时结论保留并标注替代关系，不直接删除
