# 菜单栏 RSS / Tasks 子菜单 + 定时抓取 实施计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** MenuBarManager 增加 RSS 和 Tasks 子菜单，支持定时自动抓取 RSS，重载配置时刷新菜单

**Architecture:** `NSMenuDelegate.menuWillOpen` 动态刷新菜单；RSS 抓取用 `Task` + cancel 实现新胜旧；RSSManager 新增 `startAutoFetch(intervalMinutes:)` 定时器；ConfigTypes 默认 `updateInterval: 60` 分钟

**Tech Stack:** Swift 5.9+, AppKit (NSMenuDelegate, NSMenuItem), DispatchSourceTimer

**Memory Impact:** < 3KB（NSMenuItem 对象 + Task 引用 + Timer），baseline ~18MB 不变

---

## 内存占用分析

| 新增组件 | 估算 |
|----------|------|
| NSMenuDelegate + rssMenuItem / tasksMenuItem 引用 | ~300 bytes |
| RSS 子菜单 (3 个 NSMenuItem，每次重建) | transient ~600 bytes |
| Tasks 子菜单 (N 个 NSMenuItem，每次重建) | transient ~1KB |
| rssFetchTask 引用 (最多 1 个活跃) | ~8 bytes (指针) |
| RSSManager.autoFetchTimer (DispatchSourceTimer) | ~1KB |
| **总计 physical footprint 增量** | **< 3KB** |

每次 menuWillOpen 重建时旧 NSMenuItem 被 ARC 释放。Timer 在 RSSManager 生命周期内常驻，内存可忽略。

### Task 1: RSSManager 加定时自动抓取 + 改默认间隔

**Objective:** RSSManager 支持按 `updateInterval` 分钟自动抓取 RSS

**Files:**
- Modify: `Sources/RSS/RSSManager.swift`
- Modify: `Sources/Core/ConfigTypes.swift`

**Step 1: RSSManager 加定时器**

```swift
// 新增属性
private var autoFetchTimer: DispatchSourceTimer?

// 新增方法
func startAutoFetch(intervalMinutes: Int) {
    guard intervalMinutes > 0 else { return }
    stopAutoFetch()
    let t = DispatchSource.makeTimerSource()
    t.schedule(deadline: .now() + 10, repeating: .seconds(intervalMinutes * 60))
    t.setEventHandler { [weak self] in
        Task { try? await self?.fetchAll() }
    }
    t.resume()
    autoFetchTimer = t
    debugLog("[RSS] Auto-fetch started: every \(intervalMinutes) min")
}

func stopAutoFetch() {
    autoFetchTimer?.cancel()
    autoFetchTimer = nil
}
```

**Step 2: ConfigTypes 改默认值**

`RSSConfig.updateInterval` 默认值 30 → 60：

```diff
-    var updateInterval: Int = 30
+    var updateInterval: Int = 60
```

以及解码 fallback：

```diff
-        updateInterval = try c.decodeIfPresent(Int.self, forKey: .updateInterval) ?? 30
+        updateInterval = try c.decodeIfPresent(Int.self, forKey: .updateInterval) ?? 60
```

**Step 2: 修改 buildMenu() — 加 RSS / Tasks 区块**

在「清空剪切板」和「退出」之间加入：

```swift
menu.addItem(NSMenuItem.separator())

// ── Tasks ──
```

同时设 `menu.delegate = self`。

**Step 3: NSMenuDelegate — 动态刷新**

```swift
public func menuWillOpen(_ menu: NSMenu) {
    refreshRSSItem()
    refreshTasksItem()
}

private func refreshRSSItem() {
    let count = (try? RSSManager.shared.unreadCount()) ?? 0
    let sub = NSMenu()

    let fetchItem = NSMenuItem(title: "抓取 RSS", action: #selector(rssFetch), keyEquivalent: "")
    fetchItem.target = self
    sub.addItem(fetchItem)

    let markReadItem = NSMenuItem(title: "全部已读", action: #selector(rssMarkAllRead), keyEquivalent: "")
    markReadItem.target = self
    sub.addItem(markReadItem)

    rssMenuItem.title = count > 0 ? "RSS (\(count) 未读)" : "RSS"
    rssMenuItem.submenu = sub
}

private func refreshTasksItem() {
    let tasks = ConfigManager.shared.config.tasks
    let sub = NSMenu()

    for task in tasks {
        let item = NSMenuItem(
            title: task.name,
            action: task.enabled ? #selector(taskTrigger(_:)) : nil,
            keyEquivalent: ""
        )
        item.target = task.enabled ? self : nil
        item.isEnabled = task.enabled
        item.representedObject = task.name
        sub.addItem(item)
    }

    tasksMenuItem.title = tasks.isEmpty ? "任务" : "任务 (\(tasks.count))"
    tasksMenuItem.submenu = sub
}
```

**Step 4: RSS Actions — 抓取（防重入） + 全部已读**

```swift
@objc private func rssFetch() {
    rssFetchTask?.cancel()          // 新胜旧：取消上一次
    rssFetchTask = Task {
        do {
            let new = try await RSSManager.shared.fetchAll()
            guard !Task.isCancelled else { return }  // 丢弃旧结果
            debugLog("[MenuBar] RSS fetch: \(new.count) new items")
        } catch {
            guard !Task.isCancelled else { return }
            debugLog("[MenuBar] RSS fetch failed: \(error)")
            NotificationManager.shared.error("RSS 抓取失败", error.localizedDescription)
        }
    }
}

@objc private func rssMarkAllRead() {
    do {
        try RSSManager.shared.markAllAsRead()
        debugLog("[MenuBar] RSS marked all read")
    } catch {
        debugLog("[MenuBar] RSS mark all read failed: \(error)")
    }
}
```

**Step 5: 重载配置时刷新菜单**

修改 `reloadConfig` action：

```swift
@objc private func reloadConfig() {
    do {
        try ConfigManager.shared.reload()
        refreshRSSItem()
        refreshTasksItem()
    } catch {
        debugLog("[MenuBar] Reload failed: \(error)")
        NotificationManager.shared.error("配置重载失败", error.localizedDescription)
    }
}
```

**Step 6: Task Actions**

```swift
@objc private func taskTrigger(_ sender: NSMenuItem) {
    guard let name = sender.representedObject as? String,
          let task = ConfigManager.shared.config.tasks.first(where: { $0.name == name && $0.enabled })
    else { return }

    DispatchQueue.global(qos: .utility).async {
        let result = TaskExecutor.execute(task.exec)
        if result.success {
            debugLog("[MenuBar] Task '\(name)' triggered OK")
        } else {
            let errMsg = result.error.isEmpty ? "exit code != 0" : String(result.error.prefix(200))
            debugLog("[MenuBar] Task '\(name)' FAILED: \(errMsg)")
            DispatchQueue.main.async {
                NotificationManager.shared.error("任务失败: \(name)", errMsg)
            }
        }
    }
}
```

## 风险与注意事项

| 风险 | 缓解 |
|------|------|
| 快速连点「抓取 RSS」创建多个网络请求 | `rssFetchTask?.cancel()` + `Task.isCancelled` guard 丢弃旧结果 |
| 重载配置后 Tasks 菜单不更新 | `reloadConfig` action 末尾调用 `refreshTasksItem()` |
| 旧 NSMenuItem 泄漏 | ARC 自动释放 |
| 定时器在 reloadConfig 后仍用旧间隔 | 调用 `startAutoFetch(intervalMinutes:)` 重启定时器 |
| `Task.isCancelled` 不取消底层 URLSession 请求 | 网络请求可能已发出，但结果被 `guard` 丢弃；URLSession 会自行超时断开 |
| `rssMarkAllRead` 未刷新菜单栏显示 | 菜单关闭后下次 `menuWillOpen` 自动重新查询 |
