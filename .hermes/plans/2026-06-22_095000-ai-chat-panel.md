# AI 快速对话面板 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 实现 Spotlight 风格 AI 快速对话面板，option+space 弹出，流式输出，失败保留已输出内容 + danger 提示。

**Architecture:** 四层分离 — 
- `SSEParser`（协议解析层）独立于业务，可单独测试
- `OpenAIClient`（传输层）纯 HTTP，`OpenAIChatRequest.stream` 控制流式
- `AIChatService`（业务逻辑层）构建消息 + system prompt + cancel，零视图依赖
- `ChatPanelController`（视图层）NSPanel + NSTextView 输入/输出

**Tech Stack:** Swift + AppKit, Carbon EventHotKey, URLSession SSE streaming, YAML 配置

## Task 2: SSEParser 独立封装

**Objective:** 抽取 SSE 解析为独立组件，方便复用与测试。

**Files:**
- Create: `Sources/Core/SSEParser.swift`

**完整代码：**

```swift
import Foundation

/// 独立 SSE（Server-Sent Events）解析器
/// 逐行解析 `data: {...}` 帧，提取内容并回调
public final class SSEParser {
    private var buffer = ""

    public init() {}

    /// 喂入 Data 并回调每个解析到的 token
    /// - Parameters:
    ///   - data: 流式响应 chunk
    ///   - onToken: 每个 content delta（可能为空字符串，表示忽略）
    /// - Returns: 是否收到 `[DONE]` 信号
    @discardableResult
    public func feed(_ data: Data, onToken: @escaping (String) -> Void) -> Bool {
        guard let str = String(data: data, encoding: .utf8) else { return false }
        buffer += str
        return parseLines(onToken: onToken)
    }

    private func parseLines(onToken: @escaping (String) -> Void) -> Bool {
        let lines = buffer.components(separatedBy: "\n")
        buffer = lines.last ?? ""

        for line in lines.dropLast() {
            let trimmed = line.trimmingCharacters(in: .whitespaces)
            if trimmed.hasPrefix("data: ") {
                let jsonStr = String(trimmed.dropFirst(6))
                if jsonStr == "[DONE]" { return true }
                if let data = jsonStr.data(using: .utf8),
                   let json = try? JSONSerialization.jsonObject(with: data) as? [String: Any],
                   let choices = json["choices"] as? [[String: Any]],
                   let delta = choices.first?["delta"] as? [String: Any],
                   let content = delta["content"] as? String
                {
                    onToken(content)
                }
            }
        }
        return false
    }
}
```

**设计要点：**
- `buffer` 保留未完成行，handle 跨 chunk 边界
- `feed()` 返回 `Bool` 表示是否收到 `[DONE]`
- 不依赖任何项目类型，可单独单元测试

## Task 3: OpenAIClient 添加 `stream()` 方法

**Objective:** `OpenAIClient` 新增 `stream()`，使用 `SSEParser` 和 `request.stream` 属性。

**Files:**
- Modify: `Sources/Core/OpenAIClient.swift`

**代码：**

```swift
/// SSE 流式回调
@discardableResult
public func stream(
    request req: OpenAIChatRequest,
    baseURL: String,
    onToken: @escaping (String) -> Void,
    onComplete: @escaping (Result<Void, Error>) -> Void
) -> URLSessionDataTask? {
    let urlRequest: URLRequest
    do {
        urlRequest = try makeURLRequest(req, baseURL: baseURL)
    } catch {
        onComplete(.failure(error))
        return nil
    }

    let parser = SSEParser()
    let task = session.dataTask(with: urlRequest) { data, response, error in
        if let error = error {
            onComplete(.failure(error))
            return
        }
        guard let httpResponse = response as? HTTPURLResponse else {
            onComplete(.failure(OpenAIError.invalidResponse))
            return
        }
        guard httpResponse.statusCode == 200 else {
            let body = data.flatMap { String(data: $0, encoding: .utf8) } ?? ""
            onComplete(.failure(OpenAIError.httpError(httpResponse.statusCode, body)))
            return
        }
        guard let data = data else {
            onComplete(.failure(OpenAIError.emptyData))
            return
        }
        let done = parser.feed(data, onToken: onToken)
        onComplete(.success(()))
    }
    task.resume()
    return task
}
```

**注意：** `URLSession` `dataTask` 的回调收到的是完整 body。对于真正的流式（逐 chunk），需要实现 `URLSessionDataDelegate` 的 `urlSession(_:dataTask:didReceive:)`。这里先用 `dataTask` 起步，后续可升级为 delegate 模式。

## Task 4: AIChatService 精简版

**Objective:** 业务逻辑层：构建消息 + system prompt + cancel。**不处理重试**。

**Files:**
- Create: `Sources/Chat/AIChatService.swift`

**完整代码：**

```swift
import Foundation

/// AI 对话服务 — 纯逻辑层，零视图依赖
public final class AIChatService {
    public static let shared = AIChatService()
    private var currentTask: URLSessionDataTask?
    private let lock = NSLock()

    private init() {}

    public var isStreaming: Bool {
        lock.lock(); defer { lock.unlock() }
        return currentTask != nil
    }

    public func cancel() {
        lock.lock()
        let task = currentTask
        currentTask = nil
        lock.unlock()
        task?.cancel()
    }

    @discardableResult
    public func chat(
        messages: [OpenAIChatRequest.Message],
        onToken: @escaping (String) -> Void,
        onComplete: @escaping (Result<Void, Error>) -> Void
    ) -> URLSessionDataTask? {
        cancel()

        let config = ConfigManager.shared.config
        guard !config.ai.apiKey.isEmpty else {
            onComplete(.failure(AIChatError.missingAPIKey))
            return nil
        }

        var allMessages = messages
        if let system = chatSystemPrompt() {
            allMessages.insert(.init(role: "system", content: system), at: 0)
        }

        let request = OpenAIChatRequest(
            model: config.ai.model,
            messages: allMessages,
            stream: true
        )

        let client = OpenAIClient(apiKey: config.ai.apiKey)
        let task = client.stream(
            request: request,
            baseURL: config.ai.baseURL,
            onToken: onToken,
            onComplete: onComplete
        )
        lock.lock()
        currentTask = task
        lock.unlock()
        return task
    }

    private func chatSystemPrompt() -> String? {
        return PromptManager.shared.prompt(for: "chat")
    }
}

public enum AIChatError: Error, LocalizedError {
    case missingAPIKey

    public var errorDescription: String? {
        switch self {
        case .missingAPIKey: return L10n.Translation.missingApiKey
        }
    }
}
```

**分工明确：**
| 层 | 组件 | 职责 |
|----|------|------|
| 协议解析 | `SSEParser` | SSE 帧 → token |
| 传输 | `OpenAIClient` | HTTP 请求/响应，使用 `SSEParser` |
| 业务 | `AIChatService` | 构建消息、system prompt、cancel |
| 视图 | `ChatPanelController` | 面板 UI、快捷键、错误展示 |

`OpenAIClient` 与 `AIChatService` 不重叠：前者只管 HTTP 通信，后者管对话逻辑（消息组合、配置读取、取消）。

## Task 8: ChatPanelController 面板视图层

**Objective:** 新建面板控制器，管理输入/输出/快捷键/错误展示。

**Files:**
- Create: `Sources/Chat/ChatPanelController.swift`

**架构：**

```
ChatPanelController
├── ChatPanel (NSPanel 子类, performKeyEquivalent)
│   ├── inputScrollView → ChatInputTextView (NSTextView 子类)
│   └── outputScrollView → ChatOutputTextView (NSTextView, 只读, 初始隐藏)
├── AIChatService.shared
├── previousFrontmostApp: NSRunningApplication?
└── accumulatedOutput: String (流式累积)
```

**面板布局：**

```
┌─────────────────────────────┐
│ (输入框, 默认 3 行高度)      │  ← ChatInputTextView
│ shift+enter 换行            │
├─────────────────────────────┤
│ (输出区, 初始隐藏)           │  ← ChatOutputTextView (只读)
│ 流式响应内容 (纯文本)        │
│                             │
│ ⚠️ 请求失败: connection lost │  ← 红色 danger，追加在末尾
└─────────────────────────────┘
```

**快捷键表：**

| 按键 | 位置 | 行为 |
|------|------|------|
| `esc` | `ChatPanel.performKeyEquivalent` | `close()` |
| `cmd+enter` | `ChatPanel.performKeyEquivalent` | 触发对话 / 取消当前 |
| `shift+enter` | `ChatInputTextView.keyDown` | 插入换行 |
| `enter` | `ChatPanel.performKeyEquivalent` | 粘贴输出（仅输出有内容时） |
| `cmd+c/x/v/a` | `ChatPanel.performKeyEquivalent` | `return false`，NSTextView 原生处理 |

**交互流程：**

1. **show()**：保存 `previousFrontmostApp` → `SelectedTextService.getSelectedText(from:)` 预填 → 输入框 `becomeFirstResponder()`
2. **cmd+enter（空闲）**：`AIChatService.cancel()` → 清空输出区 → 隐藏输出 → `chat(messages:)` 发起流式
3. **cmd+enter（流式中）**：`AIChatService.cancel()` → 保留已输出内容 → 重新发起（清空旧输出开始新对话）
4. **onToken**：追加到 `outputTextView.textStorage.mutableString` → 首次 token 显示输出区并展开面板
5. **onComplete(.failure)**：保留已输出内容，底部追加 `\n\n⚠️ \(error.localizedDescription)`（红色 `NSColor.systemRed`）
6. **enter（输出有内容）**：走粘贴流程 → `close()`
7. **相同快捷键再次按**：面板可见 → `close()`
8. **close()**：`cancel()` 流 → `orderOut` + `hide(nil)`

**面板高度动态调整：**
- 初始：输入框 3 行 + padding (~120pt)
- 输出出现：追加 `min(需要的高度, 屏幕高度 × 40%)`，用 `NSAnimationContext.runAnimationGroup` 做平滑 resize

**粘贴流程（复用 PasteHelper）：**
```
NSPasteboard.general.clearContents()
NSPasteboard.general.setString(outputString, forType: .string)
→ orderOut + hide(nil)
→ didActivateApplicationNotification observer → schedulePaste(to: target)
```

## 风险与 Tradeoffs

- **`URLSession.dataTask` 非真流式**：`dataTask` 回调收到完整 body。真流式需实现 `URLSessionDataDelegate.didReceive data`。先用 `dataTask` 起步，后续可升级。
- **`option+space`** 冲突较少，但也需在 README 注明快捷键。
- **面板高度动画**：AppKit `NSAnimationContext` 可做 frame resize，不如 SwiftUI 流畅但够用。
